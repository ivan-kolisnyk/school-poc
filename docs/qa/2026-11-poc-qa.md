## 6. Motion audit (design-motion-principles, audit mode)

**Context:** a school website for families on phones; DESIGN.md 12 sets the limits (150 / 200 / 400ms, `cubic-bezier(.2,.8,.2,1)`, only transform, opacity, colour and background animate; one hero entrance; no scroll-triggered motion). **Weighting:** Emil Kowalski primary (restraint, frequency: nav and menus are used daily), Jakub Krehel secondary (production polish), Jhey Tompkins not applied (DESIGN.md 12 rules out playful motion). The workflow asks the user to confirm the weighting; as a dispatched implementer the weighting follows DESIGN.md 12 instead. The report is written here in terminal mode rather than as an HTML file in `motion-audits/`.

| Interaction | Measured | DESIGN.md 12 | Verdict |
|---|---|---|---|
| Hero entrance | Headline: `hero-enter`, 320ms, 12px fade-up, `cubic-bezier(.2,.8,.2,1)`; button pair the same with an 80ms delay (ends at 400ms). Pure CSS, `both` fill, nothing hidden if it never runs | Headline and buttons fade up once, ≤ 400ms | Pass |
| Mobile menu | Open: opacity + 8px `translateY`, 200ms; close: 150ms (exit quicker than enter), unmounted after the exit; focus returns to the button on Esc | Slides/fades in over 200ms | Pass |
| Card hover | News photo zooms 1.03 inside its frame (200ms); title underlines; no lift, no shadow | Photo zoom 1.03, no lift shadows | Pass |
| Button press | `translateY(1px)` with no transition on press, 150ms back on release; hover darkens the fill 8% (150ms); secondary's gold bar fades in | Hover 150–200ms, press down 1px | Pass |
| Nav | Gold underline grows in with `scaleX` (150ms); sub-menu chevron rotates on open (state, not hover) | Underline grows in | Pass |
| Quick tasks | Background and gold bar fade, 150ms | Colour/background only | Pass |
| Link-row chevron | Slid 4px on hover | Hover: colour, background, underline only | **Fixed** (removed, fix 11) |
| Header shadow | Opacity fade, 200ms, once the page scrolls | Shadow on sticky header only | Pass |
| Reduced motion | Global rule shortens every transition and animation; hero and menu explicitly rest; opacity 1 everywhere | Everything rests; nothing stays hidden | Pass |

**Through Emil's lens:** the right things are still. Nothing animates on scroll, the desktop dropdowns open instantly (a frequent action), the press is instant and only the release eases. The one hover nudge that crept in (link-row chevron) is gone. **Through Jakub's lens:** one custom ease everywhere, exit faster than enter on the menu, the entrance never leaves content hidden, and reduced motion is handled both globally and per component. No motion gaps that matter: the search panel and alert dismissal switch instantly, which suits a restrained school site.

**Motion audit totals:** 0 Critical · 1 Important (fixed) · 0 Opportunities pursued (DESIGN.md 12 rules out added motion).
